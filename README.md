## Asset guidelines

- Keep filenames lowercase, short, and stable.
- Prefer SVG for scalable marks and logos; use PNG for social previews and raster-only contexts.
- Embed images using the `raw.githubusercontent.com` URLs above.
- Do not overwrite `qiro-banner.png` unless the original artwork is intentionally updated.
- This repository stores brand assets; the Baileys-derived package source is maintained separately.
